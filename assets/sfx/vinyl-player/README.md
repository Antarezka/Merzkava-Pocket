# Vinyl Player SFX

Drop candidate vinyl-record playback ambience files in this folder.

## Intended sound
- Continuous, subtle vinyl surface hiss/crackle while music is actively playing.
- Optional irregular, quiet pops/clicks layered naturally over the continuous bed.
- No loud electric buzz, DJ scratching, needle-drop sting, or stop/start effect as the main loop.

## File guidance
- Preferred: WAV or OGG; MP3 is also acceptable for evaluation.
- Keep the original downloaded filename and extension.
- Include a source/license note for every file in `SOURCES.md` (source page URL, creator, license, attribution requirement, and download date).
- Only add files that are licensed for the intended app use. Do not commit files whose license is unclear.

## Integration notes
- These are candidate assets only. Adding a file here does not automatically enable it in the player.
- The selected ambience should loop smoothly and play continuously only while the record/music is playing.
- Pause/stop should silence the effect; changing tracks should not create an unnecessary gap.
- Keep the effect quiet beneath the music.

You can upload files directly into this folder through GitHub's web interface.
