# Homepage Navigation Panel — Torn & Painted (Concept 27)

Status: Selected visual direction

## Approved direction

Concept 27, **Torn & Painted**, is the selected silhouette direction for the Merzkava Pocket homepage navigation dock.

The panel combines:
- A main silhouette inspired by naturally torn paper, with irregular, non-uniform edges rather than a regular geometric bevel or zigzag.
- A secondary offset paper layer, subtly visible behind the main panel to create a cut-paper collage effect.
- Dry-brush / painted strokes that break beyond the panel contour as restrained accents, suggesting hand-painted movement.
- A readable, stable central surface so navigation icons and labels remain clear at mobile size.

## Preserve the existing icon direction

Keep the previously selected **Arcane Fusion** navigation icon treatment:
- Individual asymmetric rounded-cut icon tiles.
- Thin Imperial Gold outline on inactive tiles.
- Deep Ink Black tile surface and Pale Silver-Blue inactive icon artwork.
- Electric Lime active tile with Ink Black icon artwork.
- Active tile may rise slightly and rotate subtly.

## Palette

- Ink Black: `#17191B`
- Electric Lime: `#EFFE59`
- Imperial Gold: `#F0B10A`
- Pale Silver-Blue: `#DEE4F4`
- Muted Slate: `#747788`
- Parchment / Ivory: `#F1EBDD`

## Implementation guidance

- Treat Concept 27 as the approved visual reference, not as a final production asset.
- Avoid mechanically repeated triangular teeth; torn edges should feel irregular and organic.
- Keep the brush marks selective. Do not make every edge noisy or reduce label/icon legibility.
- Preserve the Quest Console horizontal RPG command-dock layout and the existing homepage baseline.
- This approval applies to the homepage navigation panel only. It does not change the Floating Control screen or other UI surfaces.
- Do not replace the saved homepage baseline or the separate Arcane Fusion icon-direction note; this document supplements them.
