# Merzkava Pocket — Design Review APK

Installable Android review shell for the approved Pocket homepage.

Includes the kept homepage composition, Dark and White themes, Home / Game / Daily Log-in / Settings, nested Game navigation (Home Base → City → World Map), double torn-paper toolbar, upper-right brush strokes, and a CSS television pull-cord head based on the Merzkava APK TV-control ornament.

APK filename format: Merzkava-Pocket-v.0.01.001-xxxx.apk
Version format: v.major.minor.patch-hash (example v.0.01.001-abcd).

This is a design-review build, not production Pocket. It does not implement production authentication, the native Floating Control service, or live game systems. It uses the Android debug signing key generated by the build environment and does not access repository signing secrets.
